# Understanding two heart-related tests

This is an educational reference summary prepared for a synthetic-data hackathon demo. It is not a patient record, diagnosis, prescription, or substitute for clinical review.

## BNP and NT-proBNP blood tests

BNP and NT-proBNP are substances measured in blood. Clinicians may use these results, together with symptoms and other tests, when evaluating possible heart failure. A result alone does not tell a patient which condition they have. The meaning of a result depends on the specific test, the laboratory's reference information, and the person's clinical context.

Source: MedlinePlus, [Natriuretic Peptide Tests (BNP, NT-proBNP)](https://medlineplus.gov/lab-tests/natriuretic-peptide-tests-bnp-nt-probnp/).

## Electrocardiogram (ECG or EKG)

An ECG records the heart's electrical signals. It can show heart rate, rhythm, and the timing of electrical activity. An ECG result does not diagnose a heart condition by itself; a clinician interprets it alongside symptoms, history, and other test results.

Source: MedlinePlus, [Electrocardiogram](https://medlineplus.gov/lab-tests/electrocardiogram/).

## How a patient-facing explanation should use this reference

Explain what each supplied test measures and identify which facts came from the patient's actual report. Keep possible explanations separate from confirmed conclusions. If a report, value, unit, date, image, or waveform is unavailable, state that limitation instead of inventing it. Ask a qualified clinician to review any care-related decision.
