# Imaging and diagnostic synthesis: demo reference

Educational summary for a synthetic-data prototype, not a patient record or medical advice.

A chest X-ray shows structures in the chest, including the heart and lungs. It can reveal signs that prompt evaluation for heart failure, but abnormal findings can have other causes. The image and report should be interpreted by a qualified clinician with the person's history and other tests. [Source: MedlinePlus chest X-ray](https://medlineplus.gov/ency/article/003804.htm).

NHLBI describes heart-failure diagnosis as combining medical history, examination, and tests. Blood tests such as BNP, heart imaging such as echocardiography, and electrical tests such as ECG may contribute different pieces of evidence. No graph connection or single model output should be promoted to a confirmed diagnosis. [Source: NHLBI heart-failure diagnosis](https://www.nhlbi.nih.gov/health/heart-failure/diagnosis).

If only a radiology report is supplied, state that the underlying image was not independently reviewed. If an image is supplied, preserve image source, view, date, and model limitations separately from the signed clinical report.
