# Nutrition and movement guidance need clinical context

Educational, source-linked summary for a synthetic-data prototype; not an individualized plan.

For general heart health, NHLBI describes choosing vegetables, fruit, whole grains, and other nutrient-rich foods while limiting sodium, saturated fat, and added sugars. For a person with an established condition, a clinician may set different restrictions; an agent cannot infer a personal sodium, fluid, or potassium target from one test. [Sources: NHLBI heart-healthy foods](https://www.nhlbi.nih.gov/health/heart-healthy-living/healthy-foods) and [living with heart failure](https://www.nhlbi.nih.gov/health/heart-failure/living-with).

Physical activity can support heart health, but NHLBI advises discussing a new exercise plan with a healthcare provider, including type and amount. With unexplained or worsening symptoms, the physio persona should request clinical assessment before suggesting progression. A population activity target is not individual exercise clearance. [Source: NHLBI physical activity](https://www.nhlbi.nih.gov/health/heart-healthy-living/physical-activity).
